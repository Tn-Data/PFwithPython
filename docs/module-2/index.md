## What you'll be able to do

By the end of this module you will:

- Write and run Python programs, and know your way around variables, data types, operators, and expressions.
- Make your programs **decide** (`if` / `elif` / `else`) and **repeat** (`for` / `while`).
- Package logic into **functions** you can reuse, and organise them into **modules**.
- Store and manipulate collections of data with **lists, tuples, and dictionaries**.
- Read a Python error and fix it without panicking.

!!! life "Why Python?"
    Python was released in 1990 by **Guido van Rossum**, a Dutch programmer, and named after the British comedy show *Monty Python's Flying Circus*. It's easy to read (English keywords, not punctuation soup), open source, portable, and — the reason it matters for you — it is **the king of the data science kingdom**, because of libraries like NumPy, pandas, and scikit-learn. That's where Module 3 goes.
