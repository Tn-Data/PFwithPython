## What you'll be able to do

- Explain what **data science** is, and how it differs from statistics and from machine learning.
- Build, inspect, and modify a **pandas DataFrame**.
- **Filter, group, and summarise** data to find patterns.
- Handle **missing values** — which every real dataset has.
- Read and write **CSV files**.
- Produce quick **charts** straight from a DataFrame.

!!! trap "A word about loading times on this module"
    The code cells in Module 3 need the **pandas** and **matplotlib** libraries, which the browser has to download the first time you press Run on a page — roughly 10–20 MB on top of Python itself. Expect the first Run on each page to take **20–40 seconds** on a normal connection, and to be instant after that.

    If you're on a slow or shared connection, run the cells on one page at a time rather than opening all five at once. The download is cached by your browser, so it only hurts once.
