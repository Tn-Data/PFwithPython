## How this site works

- Every grey-and-dark code box is **real, runnable Python** — press **Run**. The first press on any page takes a few seconds while Python loads in your browser; after that it's instant.
- You can edit the code before running it. Nothing you type here can break anything, and nothing leaves your computer.
- Each module ends with a short **Check yourself** quiz.

!!! life "Built with"
    This site is [MkDocs](https://www.mkdocs.org/) with the [Material](https://squidfunk.github.io/mkdocs-material/) theme, plus a small custom extension (`hooks/fences.py`) that turns fenced code blocks into runnable cells and quizzes. See the repository `README.md` for how to add a new lesson.
